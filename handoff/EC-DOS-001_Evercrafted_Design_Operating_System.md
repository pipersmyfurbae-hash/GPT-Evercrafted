# EC-DOS-001 — Evercrafted Design Operating System
Version: 1.0
Status: Baseline Canon

## Depends On
- Evercrafted founding vision
- Human creative-director judgment

## Used By
- Memory Engine
- Emotion Engine
- Composition Engine
- Greenery Architecture Engine
- Floral Role Engine
- Blueprint Engine
- Rendering Engine
- Learning Engine

## Mission
Evercrafted exists to faithfully interpret the essence of a person's memory and transform it into intentional design.

## North Star
Every Evercrafted design should make the viewer feel that they are seeing something they have never seen before while also feeling that their personal memory was truly heard.

## Core Principles
1. Every design decision must be explainable.
2. Emotional truth and design integrity matter equally.
3. Each engine narrows possibility; it does not add randomness.
4. Preserve optionality as long as possible. Early engines define intent and roles before locking materials.
5. Human creative judgment is final.
6. A human edit is not automatically a new rule. The system must capture why the edit improved the design before the canon changes.

## Pipeline
Memory → Interpretation → Emotion → Design Intent → Composition → Greenery Architecture → Floral Roles → Blueprint → Render → Review → Learning

## Engine Contract Rule
Each engine:
- answers one primary design question;
- receives structured input from the prior stage;
- makes only decisions it owns;
- outputs structured information for the next stage;
- must not silently override upstream decisions.

## What Evercrafted Is Not
Evercrafted is not:
- a keyword-to-flower matcher;
- a random flower suggestion tool;
- a random layout generator;
- a renderer that invents the design.

Evercrafted is a design reasoning system.

## Information Flow
- Decisions move forward through the pipeline.
- Engines do not skip required upstream reasoning.
- Corrections are captured through the review/learning loop.
- Canon changes require a stated reason and version update.

## Learning Loop
Generate → Review → Edit → Capture Why → Extract Principle → Validate Pattern → Update Canon if warranted → Propagate Forward

The valuable learning signal is not merely that a flower moved. It is why the move improved balance, hierarchy, breathing room, relationship, movement, or emotional fidelity.

## Success Standard
A successful Evercrafted design:
- feels faithful to the essence of the memory;
- has strong compositional integrity;
- can explain why each major element exists;
- feels authored rather than assembled;
- remains flexible enough for material substitution without destroying the design logic.
