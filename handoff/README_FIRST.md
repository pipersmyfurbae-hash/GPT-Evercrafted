## Current Build Principle
Do not begin from species, flowers, or rendering.

The current sequence is:
Emotional/Design Intent → Composition → Greenery Architecture → Pockets → Floral Roles → Inventory → Blueprint → Render → Review/Learning

The blueprint is the source of truth.
